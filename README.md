# 🦫 чебурашка-запрет v1.0.0

Кастомная сборка утилиты для обхода DPI на базе **zapret v1.10.0**. ДЕЛАЮ ИНТЕРНЕТ СВОБОДНЫМ!

🚀 **Главная цель сборки** — обход блокировок YouTube и Discord в один клик без сложных настроек.

---

## ✨ Особенности сборки
* **Все настроено:** Оптимальные конфиги для обхода актуальных блокировок уже внутри.
* **Запуск в один клик:** Просто открываешь, и всё работает.
* **Легковесность:** Не нагружает систему и сеть.

---

## 📦 Как запустить

1. Скачайте `ZIP` или `RAR` архив из раздела **Releases** (Релизы) справа.
2. Распакуйте архив в удобное место.
3. Нажмите правой кнопкой мыши на **`Cheburashka Service`** и выберите ✨ **Запуск от имени администратора**.
4. Выберите пункт **`1`**, и утилита начнет обходить блокировки.
5. Чтобы отключить — просто закройте окно программы.

Перед установкой убедитесь, что у вас отключены другие аналогичные утилиты ( например, *GoodbyeDPI* или активные *VPN-клиенты*), так как они могут конфликтовать друг с другом за сетевой трафик.
