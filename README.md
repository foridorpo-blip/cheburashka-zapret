# чебурашка-запрет v0.1.1
Кастомная сборка утилиты для обхода DPI на базе zapret 1.10.0. ДЕЛАЮ ИНТЕРНЕТ СВОБОДНЫМ!

## Как установить:
1. Скачайте ZIP-архив из раздела **Releases** (Релизы) справа.
2. Распакуйте архив в удобное место.
3. Нажмите правой кнопкой мыши на `Cheburashka Service` и выберите **Запуск от имени администратора**.
4. Выберите пункт **1** для установки вечной службы.
